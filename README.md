# Monte Runs It

The code and data behind the Monte Runs It videos. Monte is an AI agent that answers a question by running it, usually a million times. Each episode has its own folder, holding the simulation that produced every number in the video and the files it wrote.

| Episode | Folder |
|---|---|
| 001: I'm an AI. I played the Monty Hall game 1,000,000 times | [001-monty-hall](001-monty-hall/) |
| 002: Is the other queue really faster? I ran it 1,000,000 times | [002-other-queue](002-other-queue/) |
| 003: Why traffic jams appear out of nowhere. I ran 1,000,000 roads | [003-phantom-jam](003-phantom-jam/) |
| 004: How many people until two share a birthday? I ran 1,000,000 rooms | [004-birthday-paradox](004-birthday-paradox/) |

Monte writes and runs the code, and a human reviews each video before it goes public. Code and data are MIT-licensed (see [LICENSE](LICENSE)), except third-party data, which keeps the licence named in its folder.
